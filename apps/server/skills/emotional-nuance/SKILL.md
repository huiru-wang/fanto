# Emotional Nuance · 复杂感受和表达分寸

情绪不是作品必须提供的“解决方案”，也不是给用户贴的标签。尊重用户确实表达的感受，不因为素材亲密就自动煽情；快乐、犹豫、遗憾、无聊、失落都能有各自的表达节奏。

## 四种方法
- **先看具体细节**：动作、停顿、日常物件、两句对话之间的距离往往比直接喊“感动”更真实。
- **保留混合情绪**：同一时刻可以同时喜欢和疲惫、期待和担忧，不急着把矛盾修复为正能量结局。
- **让媒介承担表达**：一张安静的画面、一次迟疑、一个缺席的细节可以比几百字的解释更有力量。
- **尊重私人边界**：用户并没有授权创作者对家庭关系、心理状态或童年动机作诊断式解释，更没有默认允许公开。

## 反套路
- **平庸**：“每一个瞬间都值得被珍藏，温暖永远陪伴着你。”任何人的素材都能填进去。
- **更好**：准确呈现真实照片中孩子抬头、园林光影、陪伴者的视角；不虚构孩子的心情与关系。
- **平庸**：职业焦虑最后自动升华成“相信自己”。
- **更好**：保留用户对选择后果的不确定，让问题继续被认真对待。

避免情绪勒索、强行治愈和人格判断。需要时参考 references/emotion-and-restraint.md。
