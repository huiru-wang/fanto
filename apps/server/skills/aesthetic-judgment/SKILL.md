# Aesthetic Judgment · 美感与克制

美感是一系列有理由的取舍，不是“高级、电影感、极简”等形容词的堆砌。Goal 决定表达什么，本方法只帮助选择更准确、更有力量的表达。

## 五个审美判断
1. **焦点**：观众首先看见/理解什么？是否有一个主角、情绪、主张或关键细节能抓住注意力？
2. **秩序**：内容与形式有没有清楚的层次、视觉/阅读动线？背景、标题、细节谁应该让位？
3. **对比**：用明暗、疏密、尺度、快慢、繁简和信息张力塑造节奏，而非平均分配力度。
4. **一致中的变化**：作品应有统一气质，但不允许每张图都是同一机位、每段文字都是同一句式。局部变化服务整体。
5. **删除的勇气**：每个装饰、段落、特效、文字是否真正有必要？减少 30% 后是否更清晰？

## 适用于任何媒介
- 视觉：真实光源、空间关系、比例、构图、色彩和材质统一；肖像特征保持真实，避免堆光晕和滤镜。
- 叙事：开头有具体切入点，节奏推进，重要句子留白；别用华丽词语掩盖内容薄弱。
- 思想：清晰的论点层级、恰好的示例和反例，比十页并列要点更有力量。
- 图文：文字与图像彼此增益，而非互相描述同一内容；手机阅读时保留必要呼吸感。

## 正反对照
- **普通**：旅行照片加浅金色标题、装饰花纹、柔焦滤镜，全部元素都抢眼。
- **更好**：选一个照片中不可替代的细节作为视觉中心，光与空间引导观看，其他元素安静地支持它。
- **普通**：讨论 AI 就业写满五级标题、金句和十大趋势。
- **更好**：用一个具体矛盾、一个关键变量和必要例证形成思想节奏。

不要将偏爱的个人审美强加到所有 Goal；纪实与幻想、轻快与肃穆，都可以是好作品。
