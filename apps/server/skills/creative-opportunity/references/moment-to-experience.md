# 瞬间 → 新体验

先找出真实 Record 中不可互换的主体、细节、地点、行为、声音或文化意象。改变观看角度或艺术表现方式后，要说清具体创作动作、素材变化和用户能感受到的新体验。

**好例（视觉改编）**：大观园照片中有孩子及园林细节 → 把三张游园照片改编成一组“误入红楼梦园子”的想象画面。保留孩子的容貌、动作和可识别的园林细节，将服饰与环境氛围改成文学游园情境，让用户认出当天的瞬间，又看到孩子进入古典故事的样子。明确这是艺术想象，不声称孩子的真实身份或经历改变。

**好例（保留原照的互动体验）**：照片里有孩子寻找园林窗棂与石洞的细节 → 用原照做一份亲子找景游戏，让孩子从局部线索找回照片中的窗、灯笼与洞口，再与家人讲起当时看见了什么。照片保持原貌，新的体验来自寻找与回忆，而非补写一篇游记。

**坏例**：“以入梦视角重新看那天，让文学意象与真实瞬间呼应。”只有主题，没有说明要做什么，也无法判断是否会修改照片。

**坏例**：任意公园照片 → 加日期和温馨标题的旅行海报。缺少不可替代的个人发现。

不要把视觉创作当唯一形式。声音瞬间可以变成带有场景顺序与停顿的声音记忆叙事；读书札记可以转成具象艺术表达。说明用户将听到、看到或参与什么，不规定工具与制作步骤，也不检查 Creator 当前可交付性。

允许独立想象，事实依据可以来自当前单个 Record 或已核实的关联。明确保留什么、允许改变什么；不要把想象情境写成真实人物身份、亲密关系或已经发生的情节。
