# 瞬间 → 新体验

先找出真实 Record 中不可互换的主体、细节、地点、行为、声音或文化意象。尝试改变观看角度、叙事视角、身份体验、艺术表现方式，而不是给照片堆风格形容词。

**好例**：大观园照片中有孩子及园林细节 → 设想以红楼梦角色体验重新观看那天的游园，保留真实人物身份作为核心约束。

**坏例**：任意公园照片 → 加上日期和温馨标题的旅行海报。缺少不可替代的个人发现。

不要把视觉创作当唯一形式。某个声音瞬间可以启发一段声音记忆叙事；一段读书札记可以启发具象艺术表达。提出的是新增体验的可能，不是具体工具可执行性的评估。

允许独立想象，但事实依据仍来自已确认关联；不要虚构人物身份、亲密关系和照片里看不到的细节。
