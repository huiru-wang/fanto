# 想法 → 新思考

选择源自用户真实问题的一个关键假设、被忽视的变量、强反例或有张力的矛盾，让用户看到原命题以外的值得探索之处。

**好例**：“AI 淘汰岗位 → 消费下降 → 企业继续裁员” → 做一次围绕这个循环的情景推演，比较“生产率收益主要留在企业”和“收益通过降价或收入传到消费者”两种假设，呈现它们如何影响需求与后续裁员，并列出判断分歧所需的证据。用户能看到原结论在哪些条件下成立，哪些环节仍不确定。

**坏例**：“探索 AI 与就业的新视角，形成更深的思考。”没有明确问题、探索方式或预期理解。

**坏例**：自动建议生成《人工智能时代的十大就业趋势》。标题宏大却没有推进原问题。

保留用户的不确定性和自由意志。观点联想不等于已经完成研究或证实推断，不要假装查阅了不存在的来源。更深的思考可以是一个更好的问题，而非一份冗长答案。
