# 碎片 → 新连接

连接必须有**记录证据**和独立于任一单条记录的新增理解。优先考察：
- 同一问题随时间的真实变化，不把早晚顺序当因果；
- 不同阶段相同愿望的不同表达；
- 两条看起来矛盾但可能都成立的事实；
- 间隔很久的回声与尚未完成的问题。

**好例**：过去记录关注 Agent 技术复杂性，近期记录关注实际用户需求 → 做一份“我的产品判断怎样变了”的对照作品，用真实原话展示前后判断、转折证据与仍未解决的问题，让用户看清哪些技术优先的判断变成了需求优先；只标出有记录支撑的变化，不把时间先后写成因果。

**坏例**：“把碎片连起来，发现成长的回声。”没有交代连接哪些事实、如何呈现或能看清什么。

**坏例**：三条普通周末记录 → 自动称为一部成长故事。没有新的洞察。

不要为展示“长期记忆”而牵强附会，不要把重复、偶然共现或语义相似升级为命运、关系或心理动机。
