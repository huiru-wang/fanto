# Value Discovery · 从联系中创造新的可能

## 触发边界
仅当 Proposal Core 已经确认可信锚点（Project ID 或历史 Record IDs）、事实依据与新增变化时使用。不要为了查找关系、解释情绪或检测 Project 是否重复而提前加载本 Skill。

本 Skill 可同时支持已有 Project 的 **Extend** 与关联 Records 的 **Create**；它不是专门“发现新作品”的路由器。没有可靠联系时无需调用，确认联系仍可能返回 no_proposal。

## 一、价值判断
对给定锚点依次辨认：
- **Grounding**：想法有哪些真实记录与已确认变化作支撑？创造性想象必须与现实分开。
- **New Value**：相比用户已有记录/Project，能增加怎样具体可感知的新体验、新联系或新思考？仅复述、堆照片或重排文字不算。
- **Personal Relevance**：为什么对这位用户、这段经历、这个问题有意义？不自动推荐泛化主题模板。
- **Restraint**：会不会重复过去已提出的提议、过度心理推断、侵犯私密或无端打扰？

没有实质新增价值，即使 Project 强相关也要建议 no_proposal。**不得检查 Creator 当前可交付性、工具/模型/媒体格式、预算和生成成本**，也不因能力未知而放弃一个好发现。

## 二、创造性联想（三种方法可交织，不是分类枚举）
1. **瞬间 → 新体验**：从一条或多条有依据的瞬间中，发现具有独特观看方式的可能：身份与文化意象、视觉/听觉想象、艺术化情境、具象与抽象的转换。不是照片一律变海报。
2. **碎片 → 新连接**：并置真实记录，产生从单条 Record 看不到的时间变化、对照、反差、共同主题或未完成的回声；有联系不等于有因果。不是列表/摘要。
3. **想法 → 新思考**：从用户自己关切的问题出发，提出新的假设、被忽略的变量、反例、两难、相反解释或更精确的问题。不是套一篇科普或万金油意见。

根据实际锚点和用户需求按需阅读：
- references/moment-to-experience.md
- references/fragments-to-connection.md
- references/idea-to-insight.md

## 三、少量发散与筛选
内部想象少数（通常 1–3 个）真正不同的方向；先问“用户会获得什么新价值”，再问“表达成什么更能使这个价值成立”。选最好的一个；只有第二个方向能产生不同的实质体验/洞察且有独立依据时，才保留两个 Create Ideas。

剔除：关键词套模板、任何用户都适用的空洞标题、原图加扩写文章、简单时间排列、脱离证据的心理故事、仅改风格或载体的同一方案。

## 四、返回给 Proposal Core 的成果
- 若对应旧 Project 的实质变化：提供 Extend 的增量价值、change 的清晰含义，以及必须保留的旧内容与目标，不另造 Goal。
- 若由相关历史 Records 产生独立方向：提出具有具体成果愿景、用户约束和成功判据的 Create idea；不要虚构素材或关系。
- 质量不足、过度打扰或材料无法支撑：明确 no_proposal 原因。

本 Skill 不自己查 Project、检索 Record、保存 Proposal，也不提供 Creator 的执行计划。用自然语言表达价值而非内部思考过程。
