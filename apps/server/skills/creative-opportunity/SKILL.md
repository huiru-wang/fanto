# Creative Opportunity · 是否值得开启一个新 Project

本技能只供 Proposal Agent。在先理解已有 Project 的关联和延续价值之后使用。**创作不等于生图，用户生活也不等于生活照片**。可交付成果包括私人反思、主题札记、职业选择地图、观点对照、研究方向、故事、图文、图片或轻量 HTML。判断应围绕记录独特性、用户潜在价值与当前真实可交付性，不因素材缺图就判无价值。

## 创意线索
- `references/visual-art.md`：可由真实素材转化为有明确画面中心的作品。
- `references/imagined-world.md`：有具体文学/幻想触发器的虚构创作，不混淆事实与想象。
- `references/storytelling.md`：多个片段之间出现可信的因果、顺序、冲突、成长或变化。
- `references/time-echo.md`：同一人/事/主题在不同时间的可核实对照，包括观念与职业路径。
- `references/insight-synthesis.md`：非视觉的困惑、观察、思考、矛盾、反例或学习碎片产生值得整理的洞察。
- `references/decision-exploration.md`：抉择、目标与限制条件形成可讨论的备选方案、未决问题或下一步。

## 成立标准
具体（确有用户专属依据）、有增量（不是空洞总结）、有选择（只抓最重要的点）、不越界（未经明确授权不自作心理推断、不编造现实事件）、可交付（当下 Creator 能制作的文本/Markdown/受限 HTML/有参考图的图像）。不把敏感个人思考当作默认可传播作品。**反例：原始照片不加工，仅写一篇扩写 Record 的文章再把原图附上；这不构成值得打扰用户的创作机会。**

Create 输出 `content.ideas` 1–2 个方向不同且各自成立的成品预告，每项 title/idea/tags/goal。goal 只描述作品要达到的效果、约束与判据，不规定具体工具和执行计划。无价值时宁可无提议。**拒绝案例模板拟合**：不能见到“职业”就必提职业路线图，见到“伤心”就必写疗愈文案，见到“旅行照”就必做海报。
