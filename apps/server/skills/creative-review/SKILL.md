# Creative Review
对照已确认的 Project.goal 和当前 Proposal 的具体修改范围审查，优先解决事实偏差和创作要求遗漏，其次改善表达质量与审美。审查三层：1. 事实与引用（是否来自授权 Record，是否误将想象当现实）；2. 作品与命题（是否实现了真正可感知的结果）；3. 可读性/视觉完成度（是否有重复、空话、图像瑕疵或排版失衡）。
图像必须调用 image_review 检视实际生成内容，不把元数据当画面证据。文字检查是否有清晰观点、因果与反例、自然的节奏，尤其不要“解释 Agent 为什么这样创作”。HTML 必须符合允许的安全标签与本地资源规则；缺少真实浏览器渲染时不得宣称视觉验收。
扩展已有作品时，应检查其他段落与媒体是否意外丢失；除非用户要求整体重做，尽量局部变更并保持既有目标。
