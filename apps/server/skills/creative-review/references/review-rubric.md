# Creative Quality Rubric

评估 5 个维度，每个维度用事实证据而不是空泛形容词：
1. **命题忠实**：本次 Create/Extend 的核心结果是否明确可见，是否误改原 Goal。
2. **事实与私密边界**：人物、时间、引用、隐含假设与真实记录对应；是否擅把心情转为诊断、将私人内容变成公共传播建议。
3. **原创表达**：是否选择了有个性的细节，而不是任何无关用户的记录都能套用的模板。
4. **多媒介完成度**：文章节奏、图像透视/身份、图文对齐、标题与留白是否服务整体，是否有断裂、重复与伪成果。
5. **改动保留**：增量更新是否保留原有好的正文、图片、顺序和引用；未授权部分是否被意外覆盖。

只对实际看过的结果下判断。image_review 不保证满足全部指标；文案需要读者体验，人像身份比较需要参考图；HTML 静态结构可校验但必须与浏览器视觉验收区分。重大错误不应发布，若无法修正应如实反馈。
