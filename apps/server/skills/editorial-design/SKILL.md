# Editorial Design
内容先于装饰。根据作品内容组织标题/导语/正文/引文/图片和注释层级；短文应方便一口气读完，长篇需要分节和可扫描信息。优先恰当字数和留白而不是大量视觉标签。
移动端 HTML 采用响应式宽度、清晰的字体层级、可见焦点和图片替代文本；正文避免极窄栏和强制高度，使用低干扰交互。多图注意节奏、比例、裁切、人脸完整和媒体引用 `fanto-media://`；避免把完整文字作为图中小字生成，复杂字排版交由 HTML/Markdown。
只能使用项目支持的 Markdown/受限 html-preview 元素与 CSS；不依赖脚本、远程资源、视频和外部字体。发布前检查内容链接与受限 HTML 结构；没有真实渲染截图不得宣称浏览器像素级视觉验收。
