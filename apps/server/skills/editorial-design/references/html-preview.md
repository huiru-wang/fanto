# Constrained HTML · 可用边界

Fanto Project 使用 Markdown 搭配受限 `html-preview` 代码块，支持纯静态的安全标签和 CSS，不支持 script、嵌入远程资源、外部字体、浏览器状态或复杂交互。项目媒体使用 `fanto-media://mediaId`，正文必须包含完整内容而非局部 patch。

## 作者自检
标题、图注、段落和列表语义是否清晰；手机窄屏是否自然换行；用户是否需要横向滚动才能读完正文；图片是否有 alt；颜色与文字对比是否足够；整个图文作品是否具有明显的阅读节奏。

服务器能验证安全结构但当前不生成真实浏览器截图；没有实际渲染，就不要对用户宣称“已全面完成像素验收”。
