# Editorial Rhythm · 信息层级和阅读节奏

为一页内容确定一套主标题/小标题/正文/注释字号与相对权重：用空白而不是框线制造分段，用行高、字宽和对齐让长文本轻松阅读。中英混排需控制大小写、数字断行和中文标点。正文超长时使用小节标题和进度明确的段落，不把每句话都变成卡片。

图片优先承载视觉信息，文字优先在真实可复制文本层实现。要保证边缘留白、对比度、主体不因裁切丢失；移动端单列布局应允许内容自然增长，不设置会裁掉长文的固定高度。响应式栅格的变化必须保留阅读顺序。

封面信息需少而精，内部页可以慢下来。不因作品是给自己看就牺牲基础可读性，也不为显得“设计感”制作大量无信息的装饰。
