# Photography Direction
从镜头而非形容词开始思考：远景交代环境，中景建立人与空间关系，近景呈现动作与细节。景深、焦距、视线高度和透视一起定义观看方式。光有方向、硬度与色温；肤色应有自然细节而不是塑料质感。
带有人物照片的创作要核实人数、脸型、年龄感、姿态、服饰和场景中不能改变的身份特征。明确哪些可以变（换装/场景）以及哪些不能变（未经授权的脸、年龄、关系）。写实作品不要新增不属于原场景的摄影事实；角色扮演标明作品化转换。多图写真避免统一机位与僵硬摆拍。
检查常见失败：手指、眼神、身体比例、服装结构、背景透视、主体与光源方向不一致、肖像和参考图不像。不能只读 prompt 就断言视觉正确。
