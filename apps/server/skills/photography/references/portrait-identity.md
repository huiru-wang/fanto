# Portrait · 一致性与人物可信度

## 参照比对
将用户参考照片与生成结果按人物逐一对照：人数、相对位置、年龄感、面部轮廓、发型、肤色、眼距、鼻口结构、表情、体型和姿态。脸部有局部遮挡时不得自信推断不可见五官。允许用户明确要求的新服装或发色，其余身份特征默认保持。

## 身体与服装
手部与肩肘关节、躯干重心、腿脚接地、衣物缝线与受力褶皱、首饰连接、头饰和头发的交界应自然。衣服可以变化但人物年龄、关系和身体结构不能被图像生成的常见审美模式替换。多图集要确保每张人物看起来是同一人而非只是同一种风格。

## 参考图不足
单靠一张角度偏侧或光线极弱的照片，不能承诺完全身份保真。没有原图对照时，image_review 只能指出图内瑕疵，不能声称人物百分百一致。
