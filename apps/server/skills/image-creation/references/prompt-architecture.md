# Image Prompt Architecture · 一张图的必要约束

顺序建议：要表达的可见结果 -> 使用哪张真实参考图及保持什么 -> 允许改变哪些部分 -> 场景几何与主体动作 -> 相机位置和光线 -> 统一的视觉语言 -> 不允许的更改。不要在一份提示词里同时放入冲突的摄影/绘画指令。

当目标是角色扮演，原人物身份、五官与年龄感优先于新场景；当目标是忠实纪录，构图、场景和物品关系优先于夸张氛围；当目标是艺术转译，应挑选参考图里最显著的形状和色彩组织方式，而不是随便换画风。

多张参考图必须来自同一作品已授权素材，明确每张承担的约束，不能将不相关照片的人或场景拼接成虚构的真实事件。要求“保留原照不修改”时，图片重生成无法保证像素级复制，应改用文档层直接引用原照。
