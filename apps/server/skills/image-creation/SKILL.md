# Image Creation
仅在明确需要新图像且有授权参考媒体时调用 image_generate：输入多个 referenceMediaIds，产出单图。提示词具体描述主体、可改变与不可改变的部分、场景空间关系、相机与光线、材质与画面取舍。不用形容词堆砌。精确文字应放在文档层，不靠图像生成模型排字。
生成后必须使用 image_review 查看**实际返回图像**，如有真实参考图应随同提供参考媒体用于对比并按原目标检验：身份人数、身体细节、构图、真实/虚构边界、视觉故障和需要修正之处。出现严重错误时调整描述或参考图重试，不能将未检查的生成图直接作为“已验收”的作品。视预算与失败风险克制重试，没有必要不额外生图。
如果视觉审核不可用，要如实反馈该限制，不宣称通过；最终保存仍由项目规则决定。
