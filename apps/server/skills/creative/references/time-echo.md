# 回声 · 同一锚点的时间延续

## 核心意图
让同一人物、地点、物品或事件的过去与现在互相照见。值得表达的不是日期本身，而是可确认的变化或持续不变的部分。

## 成立线索
至少两个可核实的时间点；Record 能确认属于同一锚点；变化或延续有具体内容：身高、动作、地方布置、物件磨损、重复的仪式、关系中的共同活动等。生日和周年只有具备这层关系才成立。

## 转化方式
可用今昔双联画、时间序列、周年记忆页或图文对照来揭示变化；必要时检索历史 Record 并验证时间、身份与相关性。保留每个时间点真实差异，不虚构中间经历。

## 审美取舍
用少数有力量的对比，而非凑满时间轴；允许“没变”成为看点；尽量让画面中真实变化自己说话，文字做引导。

## 失败边界
外观相似就当同一人/地点；只有生日字样但没有历史锚点；凭想象推断成长性格、亲属关系或感受；抹平真实年龄和场景差异。

## 正反例
- ✓ 同一个孩子去年与今年都在同一棵树前拍照：对比身高与树影，形成双联画。
- ✓ 同一工作台从空白到一年后摆满作品：用真实细节呈现积累。
- ✗ “今天是周年纪念日，给一张照片做时光回声海报”，没有过去的可确认素材与变化。
