# 异想 · 真实主体进入另一种世界

## 核心意图
把可信的真人、宠物或物件作为锚点，放进一个有吸引力且明确为虚构的世界。保留“是谁/是什么”，改变“世界怎样运作”。

## 成立线索
主体身份明确、姿态可辨，环境或动作天然联想到文学、幻想、生物、宇宙、微缩世界、角色扮演或另类物理规则。主题与素材有具体关联，而不是见到孩子就做童话。

## 转化方式
可换装、置景、转换时代或空间尺度，让洞口通往发光海底城、让园林成为文学舞台。通过画面设定产生故事感，但文案应说明“想象/仿佛/在作品中”，不能声称真的发生过。

## 审美取舍
先保证人物识别度、年龄感与核心关系，再建立一致的世界规则；有清晰的幻想看点，不堆砌发光粒子和符号。允许虚构服饰/背景等被明确预告的改动。

## 失败边界
虚构冒充旅行经历；擅改人物身份、年龄、人际关系或人数；未说明就更改用户在意的关键外观；幻想世界只有装饰没有设定。

## 正反例
- ✓ 岩洞望海：洞口成为通往海底发光城市的入口，照片中望海的人以原有模样和站姿进入幻想插画。
- ✓ 大观园：把照片里的人放进红楼文学场景，以真实面孔演绎角色装束，不伪称原照拍到了这些装束。
- ✗ “让她成为公主，拥有魔法”，没有指出真实锚点，也没有具体的想象世界。
