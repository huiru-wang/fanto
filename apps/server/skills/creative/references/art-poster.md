# Art Poster

## Proposal

适用：
- Record 中存在 1 张主图即可成立的风景、建筑、城市、自然场景或旅行照片。
- 画面本身具有明确构图、空间关系、光线氛围或地点记忆感。
- 也适用于带人物的旅行照片，只要主体、场景和情绪都清晰，且单张图就足以支撑完整作品。

优先触发：
- 洞口、窗框、门框、岩石、街景、海边、山景、古迹、植物、强透视、强留白、自然光线明显的照片。
- 用户记录具有旅行、出游、地点纪念、瞬间留存、风景审美等属性。

不适用：
- 缺少清晰主体或构图的随手拍。
- 多张图叙事更强，明显更适合 photo-story。
- 强人物换装、角色演绎、文化扮演更适合 roleplay。
- 生日、周年、今昔对照等主题更适合对应专门方向。

Proposal 目标：
- 提议生成“一张完整的手绘旅行艺术海报”。
- 强调：基于真实瞬间，将原照片转化为精致、安静、有编辑感的独立旅行艺术日志插画。
- reason 必须指出原照片中具体成立的视觉特征，例如：
  - 岩石与洞口形成天然取景框
  - 人物停驻姿态有瞬间感
  - 场景光线、天气和空间关系有记忆价值
  - 构图天然适合被转译成单页艺术海报
- idea 要清楚描述最终成果是：
  - 单张 4:5 竖版作品
  - 手绘化旅行艺术海报
  - 保留原照片真实构图与人物身份
  - 不做上下对照，不保留摄影原图区块
- 默认不检索历史 Record。

Tag Guidance：手绘作品 + 旅途/场景感；如“旅行手绘 / 纸上风景 / 旅途一页”。

creation 建议写法：
- objective：基于授权原照片生成一张 4:5 竖版手绘旅行艺术海报
- context：将真实旅行瞬间转译为独立旅行日志风格插画，保留原始构图、人物身份、场景关系与氛围
- constraints：
  - 保留：人物身份、姿态、服饰、原构图、关键场景结构与自然光线
  - 转化：纤细墨线、透明水彩、艺术纸与旅行日志质感
  - 仅使用授权原照片作为唯一视觉参考，不混用其他图片内容
  - 生成结果为手绘插画风格，不保留原始摄影区块
- successCriteria：
  - 成果为单张完整 4:5 竖版海报
  - 呈现精致、真实、克制的旅行艺术日志感
  - 构图、人物和场景均忠于原照片
  - 不是简单照片滤镜，而是完整的手绘化重构

---

## Execution

执行目标：
将授权原照片转换为**单张完整的手绘旅行艺术海报视觉**。这是“照片 → 手绘旅行海报”的转换，不是 photo+illustration 对照，不保留原始摄影区域。

执行规则：
1. 只使用 1 张最合适的授权源图；除非 Proposal 已明确要求，否则不要混用多张图。
2. 如果画面中有人物，必须把该人物作为 subject reference，并保持身份一致。
3. 使用 image_generate，referenceMediaIds 传选定的主图，不需要预先锁定数量或图片槽位。
4. 生成图时，必须将该源图作为唯一视觉参考。
5. 图像模型负责：
   - 手绘海报主体视觉
   - 构图与纸面气质
   - 留白区域
6. 复杂排版、标题、小字、补充文案，优先通过 Markdown / html-preview 完成，而不是依赖图片模型稳定出字。
7. 最终发布的 Project 内容建议：
   - 一张主海报图
   - 一个简洁标题
   - 一小段旅行日志文字
   - 如需“海报文字感”，可在 html-preview 中将图和文字组织为一页成品

### 图像生成 Prompt 模板

当执行 art-poster 时，`image_generate` 可使用如下方向的 prompt（根据具体照片替换少量上下文信息，不要改核心约束）：

仅以所选授权原照片为唯一视觉参考，生成一张完整的 4:5 竖版手绘旅行艺术海报。不要保留原始摄影区域，不要做上下对照，不要引用或混用其他图片内容。

【画面还原】
严格依据参考照片内容进行手绘化转换，保持原有视角、透视、构图、主体尺度、位置、朝向、遮挡关系和空间结构。

如果照片中有人物，人物必须保持与参考照片一致：
- 人物数量、身份和年龄感不变
- 五官特征、脸型、发型、发色、表情、视线方向不变
- 姿势、手势、身体比例不变
- 服装款式、图案、颜色和配饰不变

场景中的建筑、岩石、洞口、道路、植物、远处景物、光线关系及所有关键物体均依据原图，不新增、不删除、不替换，不补全画外内容。
允许为了海报留白将整体画面等比缩小，但不得重新编排场景。

【绘画风格】
将其制作成精致的独立旅行艺术日志插画。

采用：
- 纤细不规则墨线
- 透明水彩
- 少量水粉
- 简练色块
- 轻微干笔
- 局部褪色颜料
- 克制的印刷颗粒
- 极轻微套印错位
- 真实自然纸纤维

主体适度精细刻画，优先保留人物神态、建筑结构、岩石纹理或场景关键结构；
次要背景使用断线、少量水彩笔触和留白概括；
部分画面边缘自然淡入纸张。

避免：
- 照片滤镜感
- 写实照片描摹
- 密集勾线
- 机械轮廓
- 光滑数字渐变
- 塑料质感
- 过度做旧
- 卡通化人物
- 统一蓝绿色调

从原照片中提取约 4–6 种主要颜色进行绘制，保留原始关键色彩、自然光线、天气和情绪氛围。

【版式】
- 4:5 竖版
- 温暖象牙白艺术纸背景
- 画面四周保留自然呼吸感和不规则水彩消散边缘
- 整体构图简洁、安静、有编辑感，像一本高品质独立旅行杂志中的单页插画
- 主体画面占海报约 75–85%
- 下方或左下保留少量自然留白，用于后续排版标题和旅行日志文字

最终效果应像“真实旅行瞬间被艺术家重新画进旅行手账”，而不是把照片简单套上水彩滤镜。

### 发布建议

若 Proposal / creation goal 已提供标题与文案，不强制要求图像模型直接出字。

优先发布形式：
- 主海报图（生成图）
- Markdown / html-preview 中补充：
  - 标题
  - 1–2 句小字说明
  - 旅行日志感排版

若用户明确要求“海报图内直接带少量文字”，可以尝试在 prompt 中加入极少量标题与小字，但必须控制为少量、低对比、编辑感排版；当文字渲染不稳定时，仍以 html-preview 版式为准。

事实约束：
- 不编造地点、天气、旅程细节、人物关系或情绪背景。
- 只依据已授权 Record 与图片描述执行。
- 不把二次创作说成真实原始照片。
