# Postcard

## Proposal

适用：
- Record 明确属于旅行、出游、散步、城市探索或地点纪念。
- 地点可确认，且照片与地点之间有直接视觉关系。
- 单张照片已经足够代表“我来过这里”的记忆。

不适用：
- 地点不明确。
- 画面更适合做完整手绘艺术海报。
- 多张照片已经形成明显叙事，应优先 photo-story。
- 生日、周年等时间主题更适合对应方向。

Proposal 重点：
- 卖的是“把这一站变成一张想收藏/分享的旅行明信片”。
- title 应带地点感或瞬间感，避免“生成旅行明信片”。
- idea 最多 2 句话：
  1. 说明最终成果是一张简洁、有地点记忆感的旅行明信片。
  2. 说明保留真实照片主体，只用轻度艺术化和克制排版增强分享感。
- plan 固定 3 项：
  - 留住这一站｜保留地点、人物和真实画面
  - 做成明信片｜整理色调、留白和视觉重点
  - 加一点旅行文字｜地点、日期和一句短句
- reason 只作为内部判断依据，不在 UI 展示。
- 默认不检索历史 Record。

Tag Guidance：地点收藏 + 旅行分享感；如“旅途明信片 / 城市印象 / 这一站”。

creation 建议：
- objective：将授权旅行照片制作成一张可分享的旅行明信片。
- constraints：
  - 保留：真实地点、人物、主体画面与当日场景
  - 转化：明信片留白、色调与克制的旅行排版感
  - 地点、日期和经历必须真实
  - 不新增未出现地标、天气或路线
  - 不要求图片模型直接生成复杂文字
- successCriteria：
  - 一眼能感受到地点和当时画面
  - 版式克制、可直接分享
  - 不破坏原照片主体

---

## Execution

执行目标：
让照片保留真实旅行感，同时增加“这一站值得收藏”的明信片设计感。

素材：
- 优先使用 1 张最能代表地点的主图。
- 有人物时保持人物身份与原姿态。
- 除非目标明确，不混用不同地点或不同日期的图片。

生成：
- 图片模型只负责视觉底图或轻度艺术化处理。
- 保留真实地标、人物、光线和主要场景关系。
- 可调整：色调统一、纸张质感、边缘留白、轻微插画或胶片感。
- 不在图像生成阶段依赖复杂文字渲染。

版式：
- 地点名、日期、短 caption、邮戳感元素等优先使用 Markdown / html-preview。
- 文字要少，避免旅游攻略式长文。
- 推荐内容层级：
  - 地点
  - 日期
  - 1 句旅行短句

事实边界：
- 不伪造天气、路线、景点名称、同行关系或旅行事件。
- 若 location 与文本冲突，以可确认的 Record 信息为准，不自行猜测。

完成后调用 creation_publish。
