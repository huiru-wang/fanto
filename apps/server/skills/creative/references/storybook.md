# Storybook

## Proposal

适用：
- 儿童、宠物或明确主体在照片中有自然动作、互动或富有想象空间的场景。
- 原照片本身已经像一个“小故事的开头”。
- 用户更可能喜欢温柔、童趣、绘本化的二次创作，而不是写实写真。

不适用：
- 需要严肃纪实表达的照片。
- 人物身份不清晰。
- 必须依靠大量虚构才能成立。
- 明确文化/角色世界观更适合 roleplay。

Proposal 重点：
- 卖的是“把真实的一小段生活，画成一页自己的绘本”。
- title 应温柔、具体、有画面感，避免“生成儿童绘本”。
- idea 最多 2 句话：
  1. 说明会把原照片转成绘本页/小故事视觉。
  2. 强调保留真实人物/宠物和当时场景，只把画面变得更有童话感。
- plan 固定 3 项：
  - 留住真实主角｜人物/宠物和动作保持原样
  - 画成绘本世界｜统一插画语言、色彩和场景氛围
  - 写一小段故事｜只做轻叙事，不改写真实经历
- 默认不检索历史 Record。

Tag Guidance：绘本 + 童趣/想象；如“童话绘本 / 生活入画 / 小小冒险”。

creation 建议：
- objective：基于授权照片生成一页或一组轻叙事绘本作品。
- constraints：
  - 保留：人物/宠物身份、真实动作与原场景关系
  - 转化：绘本画风、色彩氛围与轻叙事表达
  - 不编造真实关系、年龄、台词或事件
  - 虚构内容必须明确属于创作表达
- successCriteria：
  - 一眼能认出原主角
  - 绘本风格统一
  - 文案轻、短、自然，不像儿童故事模板

---

## Execution

执行目标：
保留真实主体和瞬间，把视觉语言转成温柔、有质感的绘本，而不是把真实生活改写成虚构剧情。

生成：
- 人物/宠物必须以授权原图为身份参考。
- 保留核心外观、动作、表情倾向和身体比例。
- 允许转化：绘画材质、环境气氛、色彩、局部装饰和轻微想象元素。
- 不把儿童成人化，不改变宠物品种/外形，不新增未经确认的人物关系。

叙事：
- 可以写轻微拟人、想象或诗意句子，但要让读者明确这是创作。
- 不写“当时他说了……”“她最喜欢……”等未经记录的事实。
- 不虚构完整冒险故事覆盖真实 Record。

成品：
- 优先 1–3 张绘本化视觉。
- Markdown / html-preview 负责标题、短文与页面节奏。
- 每页文字尽量少，视觉优先。

完成后调用 project_manage(action=update)。
