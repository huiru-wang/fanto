# 成章 · 让关联片段具有叙事推进

## 核心意图
把真实的几个瞬间编成有开端、推进、变化或收束的作品；不是简单照片排列，也不要求每个事件都有戏剧性转折。

## 成立线索
可确认是同一次经历或关联事件；不同照片、文字、音频体现时间、动作、地点或关注点的变化。存在值得展开的线索，如寻找、抵达、互动、发现或归途。

## 转化方式
按真实线索筛选关键片段，通过节奏、留白、镜头距离、文字取舍组织成短篇图文、故事页、轻量 HTML 等。素材少时可以只留两三幕；不得虚构过程填补空白。

## 审美取舍
每段都推进理解，而不是每张照片平均配一句；把最强的一幕安排在合适位置；结尾可以是停留而非刻意升华。

## 失败边界
彼此无关的素材生硬串联；编造未记载的台词、情绪和事件；只靠多张照片加解释但毫无变化；为凑所谓“三幕”而重复视觉。

## 正反例
- ✓ 逛园林时先远望一座亭、沿路走近、最后在亭边停下：从“看见”到“抵达”的图文短章。
- ✓ 一组做手工照片中有材料、搭建与成品：让动作发展成为故事。
- ✗ “把这五张照片组成温暖回忆故事集”，没有讲清什么在推进。
