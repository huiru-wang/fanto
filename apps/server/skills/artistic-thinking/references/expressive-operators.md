# Expressive Operators

| 方法 | 核心追问 | 失败风险 |
| --- | --- | --- |
| 陌生化 | 换一个位置观察会出现什么？ | 纯猎奇、与 Goal 无关 |
| 象征 | 用户素材中的什么物件/动作足以承载意义？ | 万能意象套模板 |
| 对照 | 两种真实状态摆在一起会多出什么认识？ | 强造对立 |
| 视角转换 | 另一视角能表现怎样的新体验？ | 虚构身份或心理 |
| 跨媒介转译 | 换媒介是否让意义更鲜明？ | 只有形式变化无新价值 |

使用一项恰当的算子通常优于同时堆叠五项。尤其是涉及儿童肖像与家庭照片时，创作自由必须服务真实人物尊重和身份保持。
