# Artistic Thinking · 从熟悉事物中发现陌生角度

艺术表达不是凭空堆奇观，而是在用户真实素材里找到一个独特连接，使观看者发现从前没有注意到的意义。

## 可选择的思考算子
- **陌生化**：如果第一次看到这个场景，会在哪个细节上停留？尝试改变观看位置而不扭曲事实。
- **象征与隐喻**：将已有材料中的形状、动作、地点或物件提炼成具有情感/思想意义的意象；不能用万能月光、蒲公英、星河装饰一切。
- **反差**：过去与现在、动与静、现实与想象、宏大与细微之间有何真实张力？反差要源于素材，而不是强行制造戏剧。
- **视角转换**：以人物、环境、物件或时间的新视角组织体验。换视角不是擅自虚构用户身份与动机。
- **跨媒介转译**：文字可转成画面、照片可变成具有主题的艺术表达、多个瞬间可组成有叙事逻辑的作品；媒介必须产生新增体验。

## 工作方法
选一个最能改变用户观看体验的概念，基于 Goal 和真实 Record 判断是否值得继续。优先一个强表达中心，不为了展示创意而叠加五六种艺术手法。通过制作与复看验证，而不是只在 Prompt 中叙述“作品将很惊艳”。

## 正反对照
- 大观园人物照片：**平庸**是给原图加红楼梦风格标题；**进阶**是围绕真实服装、园林动线、人物动作构思一个可信的角色转换瞬间，并保留原有身份特征。
- 零散的项目记录：**平庸**是整理“技术成长路线”；**进阶**是找到从工程热情到用户价值质疑之间的真实张力，以作品让变化被理解。
- 普通人的生活记录：**平庸**是自动填入治愈模板；**进阶**是让细微的声音、动作、间隙和未说出口的部分保留自己的意义。

需要时参考 references/expressive-operators.md。艺术想象是被明确识别的创作，不应伪装成真实发生过的事实。
