# Storytelling & Reflective Writing
先确认是纪实、私密札记、观点论述、决策分析还是明确约定的虚构故事。纪实写作只引用真实记录；用户尚未确认的情绪、人格和动机不能写成确定事实。记录中的不确定、犹豫和矛盾可以是作品价值，不必总导向积极答案。
选一个清晰的中心问题，从具体场景、证据或反差进入；围绕冲突、转折、递进或对照安排段落，避免流水账/煽情/鸡汤。文字节奏应有长短变化，关键细节留白。对职业与人生思考，要区分观察、解释、反例、假设和行动；别伪装成心理咨询或确定的职业建议。
作品要让读者看到“用户经历了什么/想过什么”，而不是 Agent 如何分析的。可按需参考 `references/reflective-work.md`。
