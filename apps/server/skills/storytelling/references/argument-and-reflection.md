# Reasoning as Writing · 复杂思考与职业抉择

## 论证层次
先复述可核实的事实，再列用户的解释、可能的反例和仍不确定的条件。判断“为什么变化”时禁止把时间先后自动写成因果。职业选择要显式保留用户的优先级、限制与未决事项，不将职位声望或工资当作唯一价值。

## 结构范式（按需选择）
- 观察 -> 初步解释 -> 反例 -> 修订后的理解 -> 尚待验证的问题。
- 两个选择 -> 各自机会成本 -> 条件变化 -> 可以先做的小验证。
- 多次失败 -> 事实模式 -> 并非共性的差异 -> 更精确的问题。
以上是写作骨架，不是必须填满的模板；如果素材只支持一则短札，宁可写短。

## 用词风险
不要把用户说的“我担心”写成“事实证明”，不要把一次面试失利写成长期能力不足。保留原话的个性，弱化假大空的“终将”“一定会”。
