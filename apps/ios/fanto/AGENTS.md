# iOS Agent Guide

适用于 `apps/ios/fanto/`。当前能力与数据来源见 `../../../docs/clients/ios.md`。

## 当前约束

- 使用 SwiftUI，当前最低部署目标为 iOS 26.5。
- 根导航使用系统 `TabView`，当前为“记录 / Fanto / 我的”三个 Tab，每次启动默认进入记录页；中间 Tab 使用当前 Fanto 昵称与圆形头像，昵称超过 6 个字符时仅在 Tab 中截断。头像复用当前账号图片缓存并保留原色，选中态仍由系统 Tab 栏和强调色呈现；“脉络”入口隐藏；认证页不属于 Tab 导航。
- 优先使用系统导航、Sheet、语义颜色与原生交互，不用自定义覆盖层替代系统组件。
- 运行态数据应以 Server API 为准；Preview 可以使用样例数据，但不能把 Preview / 本地样例包装成已经接入的真实能力。
- “新建记录”可选择记录发生的日期与时间；打开后仅在已授权且无草稿地点时尝试一次前台定位，显示原生地图预览，地点与行政信息按钮位于右下角。未授权仅显示单行添加地点，二级页主动请求才询问系统权限，拒绝后通过居中 Alert 引导设置。用户可移除定位建议，或通过搜索结果、地图选点与当前位置编辑地点。当前位置与地图选点共用 MapKit 地址映射，同时读取新版地址与旧版结构化行政字段，始终保留原始选中坐标；地址未识别时保留地点并提示重新选点。编辑地图底部“当前位置”按钮重新定位，地图其他区域仍支持选点。地点保留本体、国家、省/州、城市、区和坐标；地点卡紧接正文与图片，展示地点本体和行政区。创建页只支持文字与最多 5 张图片，不提供录音入口。媒体上传后创建 Server Record，并以最新列表刷新本地 Store；缓存不能替代服务端事实来源。
- API Client 使用 HTTPS 公网域名；正式运行态身份统一来自 Fanto access JWT，不再允许客户端通过 `x-user-id` 或固定测试 token 指定用户。
- Google 登录依赖 `Supporting/Info-*.plist` 中的 iOS Client ID、Server Client ID 与 reversed URL scheme；占位值只能用于未配置构建，真机登录前必须替换。
- Apple 登录依赖 `fanto/fanto.entitlements` 中的 Sign in with Apple capability；Server 的 `APPLE_ALLOWED_CLIENT_IDS` 必须包含 iOS Bundle ID。
- 认证恢复与本地快照准备共用同一个稳定的品牌启动页，不重复创建或播放入场动画。本地资料与 Record 快照恢复后即进入根导航，Records、Fanto 最近会话与资料查询在主界面后台执行，不预加载隐藏的 Projects；网络读取失败不能阻塞进入主界面，页面自行呈现既有失败与重试状态。

## 缓存约束

- 资料缓存以 `docs/clients/ios.md` 的“客户端缓存”为准。Fanto 设置、用户资料及账号信息启动恢复快照并查询一次，页面复用共享 Store；不加定时刷新或 TTL，显式刷新和保存确认按资源更新。
- 图片统一使用媒体 ID / variant 缓存，不能用短期签名 URL 作图片身份；裁切结果上传后预热缓存，默认头像仅用于未设置头像，加载中不可闪回默认头像。
- 缓存严格按账号及认证会话隔离；退出立即失效并清理，旧请求不可写入。缓存不能覆盖编辑草稿或替代版本冲突处理。缓存回归入口为 `sh apps/ios/tests/run-cache-tests.sh`，真机交互由用户验收。

## UI / 状态约束

- 返回与确认使用语义主前景色，单项保存按钮放普通尾部工具栏，用原生对勾并保留无障碍名称；玻璃背景不随编辑状态变化，未改动为灰色且禁用，有合法改动时用语义主色且可点击；强调色用于内容控件及主 Tab 选中态。设置列表统一系统 44pt 最小行高，允许 Dynamic Type 扩展。不通过 push 子页隐藏 Tab 栏后再延迟恢复；对话初始定位只执行一次，返回不重新滚动。

- 图片导入使用原控件覆盖层显示进度，裁切 / 上传 / 绑定进度替换顶部确认图标，不向内容插入 loading 行；错误通过系统 Alert 展示，不能挤动裁切窗口。
- “我的”顶部不显示标题文字，使用系统 NavigationStack、List / Form、语义字号和 SF Symbols；不自绘导航栏、返回按钮或底部 Tab。顶部显示相伴天数、记录数与亲密度三列统计，由当前账号统计 API 返回并缓存；记录数为服务端总数，创建 / 删除后定向刷新，不能用分页长度代替；亲密度12为服务端标记的占位值。点击昵称编辑用户头像、背景图、昵称、单行签名。用户资料走独立 Profile API，不复用 Fanto 设置。
- 用户背景图 purpose=user_cover，4:3裁切、最多1600×1200和2 MiB；背景延伸顶部安全区，随滚动退场。用户头像 purpose=user_avatar；裁切页只上传裁切结果，裁切上传成功后立即 PATCH 绑定对应头像或背景图；昵称、签名进入各自二级页单独确认保存，不插入底部保存进度行。每次只提交当前字段，保存失败在当前单项页保留输入并展示真实错误；同字段版本冲突需确认。单项页退出后不保留未保存草稿。
- 外观和强调色使用原生 Menu / Picker，当场生效；左侧行名称与菜单来源分离，偏好行使用系统默认行高，色点用原色位图避免统一染色；设置行图标使用语义主前景色，不随强调色变化；外观仅跟随系统 / 浅色 / 深色，强调色仅九种预设，均保存到设备 UserDefaults。不提供黑色强调色；原本选择黑色的本机偏好回退为蓝色。
- 账号页读取本人登录方式并支持退出；退出清除 Keychain 与当前账号缓存，进行中的 Token 刷新不得恢复已退出会话。版本展示继续保留；“我的”、数据与隐私、帮助与反馈、关于及 Fanto 设置只保留无标题分块；帮助反馈与关于协议拆成独立入口，不显示宣传语或资料说明块。退出登录与清除对话记录使用系统中央 Alert 二次确认；清除创建空白会话并 PATCH sessionId，确认绑定后重置消息、草稿、分页与恢复状态，写回共享设置缓存；失败保留旧会话。旧会话、角色与记忆不物理删除，生成 / 停止 / 恢复 / 清除期间禁止重复操作。新增存储与缓存、导出数据、数据处理与授权、注销账号、反馈 / 联系支持入口目前仅为页面框架，必须显示尚未开放，不调用写入 / 删除 API。使用帮助、使用条款、隐私政策交给系统浏览器打开官网 /help、/terms、/privacy；官网内容后续发布。清除对话记录仅放在 Fanto 设置，不放“我的”；不提供记忆管理入口或开源许可入口，关于详情只显示版本号；不提供系统权限设置项。

- Fanto 设置只从主对话左上头像与昵称进入，右上不保留设置图标。昵称有独立设置行和二级编辑页，不显示简介、基本资料子页、角色预览或恢复默认头像；设置首页不放保存按钮，昵称和四项角色分别在自己的编辑页使用右上对勾保存；版本化 PATCH 只提交当前字段（roleConfig 只含当前子键），失败保留当前输入，版本冲突必须明确处理。角色编辑器限制可视高度、允许换行并在框内滚动。
- 头像使用 PhotosPicker 选择新图，裁切窗口与圆形遮罩固定，仅图片拖动和缩放；取消 / 返回及对勾保存放在系统顶部导航，不提供重置构图按钮；点击裁切页保存后仅上传裁切 JPEG 并立即绑定当前头像字段，不提交其他设置。不保存原图、不提供下载或重新裁切旧头像。头像 purpose=fanto_avatar，与 Record 附件隔离。
- 对话正文与 Project Session 共用无气泡头像消息行；主对话读取个性头像，Project Session 保留品牌头像。输入框使用独立的原生 Liquid Glass，保留减少透明度替代样式。

- Record 创建草稿按账号保存在受文件保护的 Application Support，返回 / 下拉退出 / 进入后台自动保存文字、日期、地点、照片与已完成上传 ID；再进入恢复，手动或草稿地点不能被自动定位覆盖。草稿独立于可清理缓存，跨重新登录保留且不同账号隔离；确认提交成功后排队清除草稿与照片文件，旧写入不得复活它。不持久化短期上传凭据。创建页返回使用语义主色的系统箭头。
- Record 日历以周日为一周起点。
- Record 页面提供日历与连续时间线两种视图，使用设备 UserDefaults 的 records.viewMode 保留上次选择，首次默认日历；日历日期选择与时间线数据都以同一 `FantoStore.records` 为事实来源。
- 日历默认显示周历；周历下滑展开月历，月历上滑收回周历，两种形态横滑时必须同步移动选中日期，且 VoiceOver 需保留等价操作。
- 连续时间线按本地日历日倒序分组，底部基于 Server `nextCursor` 自动追加更早记录；追加失败不能清空当前已显示数据。
- 日历与时间线支持长按记录确认删除，使用服务端 version；成功后移除本地 Record 并保存快照，版本冲突刷新后需重新确认。取消网络请求不展示为失败；静默建议刷新保留既有内容，旧请求不得覆盖新状态。
- Record 快照按当前认证用户隔离，最多保留最近 200 条；新增与成功分页后写回快照，认证失效或账号切换时清除。未来接入更新入口时，必须在对应写入成功后同步更新或失效该快照。
- 脉络入口当前隐藏，相关页面代码保留；以下是保留模块的约束，不代表当前有可见入口。脉络页区分 Proposal 与 Project；建议决策走 Proposal API，项目详情从单个详情响应读取参考记录，不请求 Project records 接口。项目 html-preview 必须禁用脚本、桥接、任意网络资源和导航；内部图片走受保护媒体接口，签名 URL 只保留运行态。
- 脉络页的待确认 Proposal 使用堆叠卡片，按服务端顺序上下滑动浏览，保留按钮与 VoiceOver 等价操作；切换不执行接受 / 拒绝，刷新时保持当前 Proposal 身份。
- 脉络页跟进新建议；后台提议分析全程静默，信息不足时不提议。Project 详情读取通用 Session History，后台过程订阅只读 Events，继续创作走统一 Agent Stream，并与主对话共享 Tool Presentation/消息 UI；已有作品右下角允许进入同一 Project Session 继续对话，项目内容以 Server 当前版本为准。
- 音频 Record 当前主要展示播放动作与时长，不在客户端自行生成 AI 摘要。
- 停止调用通用 Session stop：202 表示请求已接受、工具仍在结束，保持原 SSE，显示“正在结束当前操作”，可编辑草稿但不可发送；终态或 History 确认空闲后恢复发送，不等数据库历史保存。已开始工具不被用户停止中断。旧请求不得覆盖新轮次；History 的 stopped 部分回复须恢复，断线核对 running/stopping，不自动重发。
- 对话图片预览读取 thumbnail，点击全屏查看读取 original；音频读取原始媒体。
- Fanto 对话按 SSE message_start/message_end 划分文本块，与工具活动按事件顺序展示，仅 done 表示回复完成；须按 Server 的 SSE `presentation` 渲染可见进度；`collect_user_input` 的结构化结果渲染为导航区域下方的逐题表单。`required: false` 的表单项允许跳过；不展示内部工具参数、结果或 interaction 标记。对话初次出现时定位到最新消息，向上滚动到历史顶部时使用 Server `nextCursor` 读取更早页，并保持阅读位置。不提供 Task 页面、Task 卡片或 Task 文件预览。

修改网络契约前先核对 `../../../docs/api/http-api.md`。

- Record 附件草稿保留上传凭据和阶段；失败不自动重试，统一提示“保存失败，请重试”，用户再次保存后才继续。图片 ready 包含服务端小图完成，客户端通过 variant 选择读取。

- 主对话断线、前台恢复和载入运行中会话时核对 History `running`；恢复期间保留内容、锁住发送，空闲后补载历史，不自动重放 POST。Tab 切换保持根视图持有的 ConversationStore 和运行任务。
