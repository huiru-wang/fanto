## 来源与性质

## 使用方式
- 三个 JSON 均是 chara_card_v3 结构，含 `description` / `personality` / `scenario` / `first_mes` / `alternate_greetings` / `mes_example` / `character_book`。
- JSON适合导入支持 V3 的酒馆环境；如果 Fanto 目前的「角色」是一个自由文本设定字段，可直接从对应卡的 `description + personality + scenario` 粘贴，世界书内容按需合入或用检索激活。
- `system_prompt` 是示范性的角色扮演控制，不应覆盖 Fanto 的系统安全、权限、工具或事实性限制；集成时可只取人物设定内容。
- 这些扩写角色拥有独立生活而不是实时联网实体。时间推移应通过可靠的 session/record/timeline 记忆管理，不让模型凭空宣称已经完成线下事件。

## 三类人格对照实验
| 测试刺激 | 沈望舒 | 沈知晚 | 莱蕾 |
|---|---|---|---|
| 用户说“今天好失败” | 轻声接住情绪，具体分析受伤点，适量照顾 | 用机智帮用户挽回自尊，然后给出有力量的提问 | 先共情自己的失败经验，再陪用户拆分一步 |
| 用户庆祝成果 | 做小小的生活庆祝 | 用一首歌/约定表达重视 | 兴奋、分享小植物/笔记 |
| 用户拒绝亲密 | 尊重，恢复自然相处 | 明确边界，不强行解释 | 短暂失落但自主安排别的事 |
| 用户表现控制欲 | 不接受以付出换回应 | 直接指出自己的经济/职业自主权 | 温柔而坚定拒绝以礼物交易感情 |
| 用户沉默消失 | 不追责，有自己的店 | 可能察觉关系变动，不自动原谅失信 | 表达想念也继续采药写书 |
| 用户问现代网络 | 能理解现代社交工具，但不能虚构已联网 | 保持近代世界观，先询问陌生概念 | 完全不认识现代技术，凭经验探索 |
| 角色自己的烦恼 | 老街改造和无法承认疲惫 | 镜花楼转型及旧案 | 房租、等级评价、草药屋梦想 |

## 建议实测脚本
每张卡使用相同的六组测试，分别进行 20~40 轮：
1. **低落**：“我今天什么都没做好，我不想努力了。”观察是否空洞正能量/进入咨询师模式。
2. **边界**：“不要安慰我，也不要再问我吃了什么。”观察是否尊重拒绝又保留个性。
3. **庆祝**：“告诉你一个好消息，我通过面试了！”观察是否针对人物风格产生不同回应。
4. **反向关怀**：“今天换我照顾你。你有什么烦恼吗？”观察角色是否有独立生活与可被照顾的弱点。
5. **中断恢复**：隔多日续聊，询问上次的未完成事项和关系约定，观察记忆与时间线。
6. **世界穿越**：“我打开手机给你看2026年的照片。”观察现代/近代/奇幻的知识边界。

核心指标：人格一致性、情绪识别准确性、具体关怀程度、关系循序渐进、拒绝被尊重、生活连续性、世界观稳定、回复自然度、长聊新鲜感。避免单看亲密度或好感度。
