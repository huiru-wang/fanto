# 已知边界与后续工作

以下内容存在于设计、数据库或源码中，但不是当前可用的端到端能力：

1. **Topic / 整理会话**：服务未挂载 Topic 路由，也未在运行入口启动整理 workflow；当前工作区也没有可运行 H5 客户端。
2. **Creation 生成**：没有可运行的 HTTP 触发入口，不能从 Record 自动生成或更新 Proposal / 脉络。
3. **脉络列表能力**：已有按类型完整列表；仍没有搜索、状态筛选、列表分页或类型详情。
4. **H5 重建**：H5 工程已删除，计划中的记录、媒体与脉络能力尚未实现或验证。
5. **iOS 新建记录与媒体**：iOS 已读取 Record 列表；新建记录、上传与媒体写入仍为本地状态。
6. **iOS 服务地址**：客户端目前硬编码 HTTP ECS 地址；Release 上线前仍需 HTTPS、地址配置化与正式认证。
7. **认证**：`x-user-id` 只是开发期用户隔离，不是正式认证或授权。
8. **异步可靠性**：图像理解和向量索引队列仅在进程内运行，不持久化、不重试、不支持多实例。
9. **媒体删除与管理**：当前没有删除上传、删除媒体或媒体列表接口。

任何新增客户端功能应先以 [HTTP API](api/http-api.md) 中实际注册的接口为边界；若需要上述能力，应先补齐服务端路由、事务语义与测试，再接入客户端。
