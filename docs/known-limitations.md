# 已知边界与后续工作

以下内容存在于设计、数据库或源码中，但不是当前可用的端到端能力：

1. **Topic / 整理会话**：H5 仍有 Topic 页面和共享 DTO，但服务未挂载 Topic 路由，也未在运行入口启动整理 workflow。
2. **Proposal 生命周期**：数据库和旧路由代码包含 Proposal、确认、拒绝逻辑；当前服务只挂载 Creation 只读路由。
3. **Creation 生成**：没有可运行的 HTTP 触发入口，不能从 Record 自动生成或更新脉络。
4. **脉络完整浏览**：接口只提供概览最多 3 项与单项详情；没有按类型完整列表、搜索、状态筛选、分页或类型详情。
5. **H5 媒体**：图片和语音捕获是交互原型，未调用上传、转写和 Record 媒体写入链路。
6. **iOS 记录同步**：iOS 记录和新建记录为本地内存状态，未接入 Record、Upload API；仅脉络只读接入服务。
7. **iOS 真机访问本地服务**：客户端硬编码 localhost，真机不可达。
8. **认证**：`x-user-id` 只是开发期用户隔离，不是正式认证或授权。
9. **异步可靠性**：图像理解和向量索引队列仅在进程内运行，不持久化、不重试、不支持多实例。
10. **媒体删除与管理**：当前没有删除上传、删除媒体或媒体列表接口。

任何新增客户端功能应先以 [HTTP API](api/http-api.md) 中实际注册的接口为边界；若需要上述能力，应先补齐服务端路由、事务语义与测试，再接入客户端。
