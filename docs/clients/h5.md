# H5 客户端

入口：`apps/h5`，React + TypeScript + Vite。

## 角色设定

设置页「Fanto → 角色设定」接入当前用户的角色配置 API，提供角色与性格、互动场景、交流规则、示例对话四项编辑。打开时读取服务端配置，保存时整体覆盖；支持读取重试、保存反馈和保存失败保留草稿。关闭会放弃未保存内容。保存成功后同一主对话下一轮生效。其他设置仍为页面内原型状态。

## 开发调试

主会话顶部展示并支持复制当前 `sessionId`。脉络默认展示当前用户全部未归档 Project，可按 queued/running/failed/completed/archived 筛选，保留服务端分页；卡片与详情展示可复制的 `projectId` / `sessionId`，未绑定时明确标注。详情另展示版本和更新时间，Proposal 详情展示 `proposalId`。ID 展示不改变服务端用户隔离。

Proposal 列表展示全部 pending/accepted/rejected 提议，标注状态并支持复制 `proposalId`，保留分页；切换 Project 状态筛选不会隐藏提议列表。已处理提议继续使用只读详情与原有查看作品入口。

执行中的已加载卡片每 5 秒按 ID 刷新，包括分页中的项目；页面隐藏时暂停，筛选内项目状态改变后移出对应列表。手动刷新读取最新列表；详情继续复用通用 Session History / Events。失败状态不等于已持久化详细失败原因，排障仍结合服务端日志。

## Project / Proposal（异步执行 V3）

- Proposal 接受：`POST /api/proposals/:id/accept` 只返回 `result.projectId`，直接打开 Project；不再调用 Session/start。
- 非归档 Project 列表默认查询 `GET /api/projects`，包括 queued/running/completed/failed；传 `status=archived` 查看归档。
- `Project.status` **仅反映当前创作执行状态**：queued 等待处理、running 正在执行、completed 成功、failed 本轮失败、archived 只读。`sessionId` 是独立的会话引用，允许 queued/running 下为空或非空；旧作品内容和封面不因状态改变而隐藏。
- 只有 completed/failed 可发起新的 Project 对话与归档；存在 Session 时，其历史在任何 Project 状态下均可读取。
- `GET /api/agent/sessions/:sessionId/history` 读取通用会话历史；`GET /api/agent/sessions/:sessionId/events` 用携带 JWT 的 `fetch` 订阅实时 SSE；继续创作通过 `POST /api/agent/stream` 使用已绑定 sessionId 和 `metadata.projectId` 直接消费 SSE，不再发送 agentId。
- 只读 SSE 订阅失败不阻止 completed/failed Project 继续发送消息。请求驱动的 `/api/agent/stream` 与 Main Chat 共用消息块渲染（Markdown、媒体、Tool Presentation），按 toolCallId 展示活动的开始/完成，不呈现原始工具 JSON；调试 ID 由页面 metadata 单独展示。SSE 断线后读取 History 并重建订阅，不自动重发 POST；`done/stopped/error` 后同步历史与 Project 内容。
- 列表存在 queued/running 时低频刷新可见项目；详情仅在 queued/running 时低频 GET 状态，不能只比较 `version`，因为状态/Session 绑定不增加内容版本。


Main Chat 与 Project Session 的图片预览请求 `variant=thumbnail`，点击查看大图请求 `variant=original`；音频读取原始媒体，缓存按 mediaId 与 variant 分开。

## 构建

`pnpm --filter @fanto/h5 typecheck`、`pnpm --filter @fanto/h5 build`。

Record 保存失败统一提示“保存失败，请重试”，保留草稿及附件上传阶段，仅用户再次点击后继续上传 / complete / 创建。列表小图与原图继续通过同一个 mediaId 的不同 variant 读取；链路见 [Media](../domain/media.md)。

## 主对话恢复

访问主对话后，站内切页保持聊天组件和进行中的 SSE，不因路由卸载中断回复。首次载入、连接异常或页面重新激活时核对 History 的 `running/stopping`；恢复期间保留已有内容与草稿，等待会话空闲后补载历史再允许发送，不自动重放消息。

SSE `finalizing` 仅为兼容进度，不显示数据库保存锁。回复在内存收尾后以 done/stopped/error 结束；历史异步保存，进程重启可能缺失最近消息，普通刷新优先恢复服务端内存。
