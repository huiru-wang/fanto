# H5 客户端

React / Vite 受控测试客户端，提供 Records、Fanto Main 对话、Fanto 设置及设置页面；未知地址回到 Records。不提供正式公开登录，使用构建时测试 refresh token 获取 JWT。

## Fanto 设置

头像裁切上传后绑定；文字使用版本化设置 API。主对话延续设置中的 sessionId，顶部头像进入 Fanto 设置，不提供会话列表、切换或新建入口。

## 记录与媒体

支持文字 / 图片 / 音频记录、录音、时间线和搜索。保存失败保留草稿与上传阶段，仅用户再次提交才重试。小图使用 thumbnail，原图使用 original，缓存按 mediaId / variant 区分；音频读取原始媒体。详见 [Media](../domain/media.md)。

## 主对话恢复

聊天组件在站内切页时保留；首次、网络异常及重新激活时核对 History 的 running/stopping，恢复期间保留内容和草稿，不重放 POST。历史通过按 Run 分页恢复，实时内容由 POST Stream 的 SSE 返回；停止保持原 SSE，工具收尾后恢复发送。主会话 sessionId 可复制供受控调试。

Markdown、媒体和 Tool 活动使用主对话共用组件，不展示原始工具 JSON 或凭据。SSE 终态及保存语义见 [Agent Runtime](../architecture/agent-runtime.md)。
