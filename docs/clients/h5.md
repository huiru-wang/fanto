# H5 客户端

当前工作区不包含可运行的 `apps/h5` 工程：旧 H5 源码已删除，因此根目录的 `dev:h5`、`build:h5` 脚本目前没有可执行目标。不能将旧页面、旧 `/api/topics` 调用或旧交互原型视为当前产品能力。

根目录的 [Record API 测试台](../../public/record-api-test.html) 是独立 H5 Demo，不属于产品 H5 工程。它在创建 Record 时提交必填的带时区 ISO 8601 `eventAt`，并按服务端返回的 `eventAt` 显示发生时间；服务端列表已按该字段倒序分页。

重建范围与接口对齐规则记录在 [H5 与 iOS / 服务端对齐方案](../../plan/2026-09-14-h5-ios-server-parity/design.md)。在该方案完成并验证前，H5 没有页面、开发用户配置或可承诺的数据刷新行为。
