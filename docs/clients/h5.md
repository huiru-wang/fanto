# H5 客户端

目录：`apps/h5`。技术栈为 Vite、React、TypeScript、TanStack Query；开发服务默认 `5174`，`/api` 代理到 `BACKEND_URL` 或 `http://127.0.0.1:3000`。

## 当前页面

| 页面 | 状态 | 说明 |
| --- | --- | --- |
| 记录列表 | 可用 | 读取 `/api/records`，支持分页。 |
| 记录详情 / 编辑 | 可用 | 读取单条记录并通过乐观版本更新。 |
| 文字捕获 | 可用 | 仅提交纯文字到 `/api/records`。 |
| 图片捕获 | 演示 | UI 显示「已添加图片」，未调用上传接口或写入媒体。 |
| 语音捕获 | 演示 | 未请求麦克风权限，未保存媒体。 |
| 话题列表 / 详情 | 不可用 | 仍请求 `/api/topics`，但当前服务未注册 Topic 路由。 |

H5 开发用户来自 `apps/h5/src/lib/model.ts` 的 `USER_ID`。这不是认证实现，生产环境不能将它视为身份机制。

## 数据刷新与失败处理

查询 15 秒内视为新鲜，页面重新可见时刷新；读取请求 20 秒超时。写请求失败时会提示保存状态不确定，建议用户刷新记录列表确认。H5 使用相对 `/api`，不在浏览器保存模型密钥。
