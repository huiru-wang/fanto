# Fanto 用户中心产品设计

状态：产品方案 / 静态原型，用户中心功能尚未实现。当前只实施隐藏 iOS 脉络、移除其启动预加载、默认进入 Fanto 与产品定位文档更新。

## 产品主线与导航

主线：角色扮演 → 连续对话 → 有记忆的相处。角色、场景、交流规则服务于沉浸和连续性；记录为可选的生活与回忆入口。

当前实际导航：记录 / Fanto，默认选中 Fanto。目标导航：记录 / Fanto / 我的，默认仍进入 Fanto。脉络页面和后端保留；本次不变更服务端 CREATIVE_ENABLED，不声称后台自动提议已关闭。

## 首页结构选择

考虑过三种结构：纯设置列表（操作直接但缺少个人感）、大封面与关系仪表盘（视觉强但挤压功能、指标缺少依据）、轻封面与资料入口（保留个人感，核心设置在首屏可见）。本版选择第三种。

视觉沿用当前 iOS：系统蓝、语义灰背景、约 22pt 圆角、原生字体和分组列表。封面控制在页面上部约四分之一，照片渐变至语义背景；资料层清晰可读。Liquid Glass 用于浮动 Tab 和工具栏，内容使用稳定的分组表面，不把所有卡片做成玻璃。提供浅色与深色版本，参考图提供布局与氛围，不复用其中人物的身份或照片。

首页布局：封面 → 用户头像 / 昵称 / 签名 / 编辑入口 → 相伴时间 → 关于我分组 → 偏好分组 → 账号与数据分组。相伴天数是一行低权重回顾，不做等级、亲密分数或连续签到。无可靠数据时不展示计数。

## 内容与职责

| 模块 | 内容 | 入口与边界 |
| --- | --- | --- |
| 个人资料 | 用户头像、昵称、简介；可选个人封面 | 点击资料区进入编辑；与 Fanto 昵称、头像分别保存 |
| 聊天中的我 | 希望被称呼的名字、可选故事身份、希望 Fanto 知道的内容 | 明确这是聊天身份；故事身份不等于现实资料，不默认写入事实记忆 |
| Fanto 记得的我 | 个人背景、重要关系、近期关注、相处偏好；查看、纠正、删除 | 显示已确认内容与可用来源；不把聊天全文作为记忆清单。删除记忆与删除聊天区分 |
| 对话体验 | 文字大小、触感反馈；后续可加入真实具备的输入 / 语音偏好 | 当前无语音对话、主动来信开关时不展示这些选项 |
| 外观 | 跟随系统 / 浅色 / 深色 | 首版沿用系统蓝，不优先开放全局强调色，避免与语义状态混淆 |
| 账号与登录 | 当前登录方式、账号信息、退出登录；后续绑定管理 | Google / Apple 已有认证；退出须清理账号级运行状态。没有绑定接口时不展示可用的绑定操作 |
| 数据与隐私 | 记忆使用说明、数据管理、隐私说明、注销账号 | 导出、清空、注销需独立契约和明确影响范围；不可做成假按钮 |
| 帮助与关于 | 使用帮助、意见反馈、隐私政策、用户协议、版本 | 首版不加会员、商城、社区、签到等与主线无关模块 |

首页分组建议：

- 关于我：聊天中的我 / Fanto 记得的我。
- 偏好：对话体验 / 外观。
- 账号与数据：账号与登录 / 数据与隐私 / 帮助与关于。

Fanto 设置维持唯一入口：对话左上头像。角色 / 场景 / 交流规则 / 示例对话不复制到用户中心。

## 原型覆盖

一版三屏：用户中心浅色、用户中心深色、聊天中的我编辑页。统计及人名均为演示数据，原型不代表接口已接入。

![用户中心原型 v1](assets/2026-10-18-fanto-user-center-v1.png)

静态原型已核对三屏布局、主要文案、浅深色及导航区分。正式实现使用可滚动列表并为浮动 Tab 预留系统安全区，保证末行可完整滚动至 Tab 上方；不将静态稿当作交互或辅助功能验收。

「聊天中的我」表单：称呼（如 Robin）、故事中的身份（可选）、希望 Fanto 了解的我（多行）、相处偏好（多行）；顶部原生返回 / 保存，段落说明身份用途。文字变化保留草稿，离开确认，保存成功才生效。实际用户资料和故事身份分别建模，不借用 user_fanto_settings。

「Fanto 记得的我」后续页面：四类筛选和搜索；条目显示内容、类别、可用来源和编辑 / 删除入口。空态“慢慢来，相处会留下记忆”，错误保留已有内容并重试；不显示虚构的记忆数量。

## 关键交互与状态

- 点击用户头像选择新图并裁切，可复用裁切交互，服务端仍需独立的用户头像用途与路径，不把用户头像作为 Fanto 头像上传。
- 封面支持选择 / 取消 / 恢复默认；默认渐变可直接使用，不能强迫上传照片。
- 普通列表原生 push，保留系统返回手势；编辑使用导航表单，保存中防重入，离开前保护草稿。
- 初次用户使用真实空态，不预填私人身份。没有用户签名时仅显示编辑提示。
- 无网时保留已确认资料，提示刷新失败；不以默认空数据覆盖服务端状态。
- Dynamic Type 下资料区和表单可纵向扩展，行高不锁死；主要点击区至少 44pt。减少透明度时导航使用不透明语义背景，减少动态效果时移除封面视差，不以颜色作为唯一选中反馈。

## 数据边界与落地顺序

FantoSettings 已接入，仅属于角色配置。现有认证不等于有完整的用户资料编辑、用户头像、封面、用户故事身份或数据管理接口。Memory 已有领域能力与 Agent 工具，不等于用户端管理页面已接入。

实现顺序：先确认用户资料与聊天身份契约；再建用户头像用途；完成“我的”与基础资料 / 退出登录；接入记忆管理；加入外观与对话偏好；最后落地数据管理。没有接口的入口延后提供，不在正式界面保留不可用操作。
