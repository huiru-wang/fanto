# Fanto：对话驱动的生成式世界状态树

> 状态：**设计讨论 / 尚未实施**
> 日期：2026-10-22
> 范围：Fanto 角色扮演 Agent 的长期世界演化、状态分支、角色认知与记忆、会话连续性。
> 本文为目标模型与验证计划，不是当前已上线能力；不要求现在修改角色卡标准、数据库或运行时。

## 1. 目标与核心定义

Fanto 兼容用户自行编写或从平台导入的普通角色卡及世界书。卡片和世界书可以描述现实人物、幻想角色、集体意识、梦境或任何其他叙事存在；**不得要求其必须有时间、地点、地图、NPC、等级、任务或某种预设字段**。

Fanto 的目标不是一套预制 RPG 数值引擎，而是**对话驱动的、开放的、因果连续且可分叉的生成式世界模拟器**：

- 角色卡与世界书提供初始设定和约束。
- 对话足以改变世界时，产生一次或多次可能的**世界增量**，并据此形成树的后继节点。
- 每次分叉可有不同数量的候选后继；默认进入当前上下文下最合理、最可能的一支，其余默认隐藏，用户可主动选择另一支继续发展。
- 每条分支都有独立的历史、人物经历与记忆。旧节点、旧分支不被新发展覆盖。
- 世界允许按需产生新对象、地点、社会关系、规则细节，以及人物的成长、认知和身体变化。
- 世界的可信度来自规则、因果、人物动机、认知视角与持续后果，而非字段数量或戏剧化程度。

**本次追加并确认的首要不变量：任何独立节点都不是完整世界状态，节点只记录从其父节点到自身发生的增量。**

## 2. 世界与节点：必须严格区分

### 2.1 世界初始状态

**W₀（初始世界）**由角色卡、世界书、明确的系统世界规则及必要的初始事实共同决定。角色卡/世界书可以随用户导入或编辑而变化，但一棵已经开始演化的树必须绑定其**不可变的初始设定版本**，以保证历史可重建。

W₀ 不需要一次性列举世界里的一切：没有写出的属性是**未知或尚未确定**，不是不存在，更不能自动填入默认地理、时间或 NPC。未来具体化的细节须与既定设定和祖先增量兼容。

### 2.2 节点仅保存增量

对任意非根节点 n：

- n 有且仅有一个 parent(n)。
- n 的核心内容是 Δₙ：相对其唯一父节点发生的**世界状态增量**。
- **Δₙ 包含整个世界任意对象的变化；人物的主观记忆、认识、信念、情绪与动机、客观身体状态、身份、关系及经历的变化，也全部是 Δₙ 的一部分。**
- 地图、地点、时间、世界规则、社会组织、物品等如果在该世界中存在，也只是可以产生增量的世界对象；均不强制出现。
- 节点可以存原因、来源对话、候选排序等元数据，但不得把该节点的内容误称为完整世界状态。

令 Path(root, n) 为从根到 n 的**唯一祖先路径**，则 n 所对应的有效世界为：

    World(n) = Apply(W₀, Δ₁, Δ₂, …, Δₙ)
             = fold(ApplyDelta, W₀, deltas(Path(root, n)))

其中 ApplyDelta 依次应用增量。**不能只看 Δₙ 来解释世界，也不能把兄弟节点或其他分支的增量加入重建路径。**

示意：

    W₀（角色卡 + 世界书 + 初始约束）
       |
       +-- N1A [Δ1A] -- N2A [Δ2A] -- N3A [Δ3A]
       |
       +-- N1B [Δ1B] -- N2B [Δ2B]
       |
       +-- N1C [Δ1C]

    World(N3A) = W₀ ⊕ Δ1A ⊕ Δ2A ⊕ Δ3A
    World(N2B) = W₀ ⊕ Δ1B ⊕ Δ2B

N3A、N2B、Δ1A 都不是“完整世界快照”。从不同路径重建出的有效世界可以拥有同名人物或同一个对象 ID，但对象状态、主观记忆和对话经历可以完全不同。

### 2.3 不可逆、可导航、不合并

- **节点不可变**：提交之后不修改其 Δ、父节点及相关已确认剧情。纠错需要产生新演化或在明确的管理操作中重建新分支。
- **演化不可逆**：同一路径中的因果历史不会被后来的事件直接抹掉。某个事实可以变得不再成立，但其曾经成立的历史仍在祖先增量里。
- **选择旧节点不等于撤销**：用户切换到其他后继，是改变正在观看/续写的分支指针；旧分支仍存在。
- **每个节点只有单亲**：不同路径即使推导出看似相同的当前表象，也不自动合并，因为经历与认知可能不同。

为加速查询，可按需维护物化快照或缓存，但它只能是对 W₀ + 路径增量的**可丢弃派生结果**，不能成为替代增量链的权威事实，不能允许缓存跨分支串写。

## 3. 世界对象：开放而非领域类型列表

世界整体可以包含任意对象。人物是世界对象中的一种，而不是比世界更高层的独立体系。地图、时间、空间、规则、机构、信仰、梦境乃至没有实体的意识，都可以在其适用世界中成为对象或对象关系。

**不强制任何对象拥有 name、kind、age、location、time、participants、scene、HP、inventory 等字段。** 模型可用自然语言或自由结构表达已确定属性；必要时为持续出现的对象建立稳定标识，以避免同名混淆和错误覆盖。对象身份是引用能力，不是固定的业务类别。

对象之间可以存在关系，但关系语义仍开放：某人相信某人、某地位于某区域、某法则约束某能力，均可由世界按需确定。

### 3.1 已知、未知与新事实

- **已确定事实**：来自初始设定或路径上的已提交增量，后续必须遵守，除非存在合理的变化事件。
- **未知细节**：允许模型按叙事需要具体化，前提是不与已知事实冲突；被明确确定后，通过增量加入该路径。
- **传闻/推测/角色信念**：并不自动成为客观真相。要保存信息来源、谁知晓、确定程度等必要语义，但不要求统一字段名。

“世界在逻辑上足够完整”不等于“数据库中预先填满所有可视细节”。可在用户观察、人物行动或剧情需要时惰性展开；被展开并确认的细节必须可追溯。

### 3.2 人物的主观性

对世界来说，“秘密实际上是 X”与“艾琳相信秘密是 Y”可以同时成立，而非冲突。某人物的记忆、误解、信念与不知道的事情，是该**人物对象在特定世界路径上的状态**。生成角色言行时，必须按其视角进行信息投影，不能将世界全知事实直接注入成角色已知事实。

角色的丰满不是传记字数多，而是其目标、欲望、局限、恐惧、矛盾、关系、经历和能力能够在情境变化时产生**多种各自有原因的合理行为**。这些行为可能真正使世界树分叉。

## 4. 对话驱动状态变化，而非逐消息造节点

每条用户消息及 Agent 回复都可能携带世界演化信息，但**不是每条消息都必须有新节点**。

判断流程：

1. 读取当前选中分支的 W₀ + 祖先增量及该分支对应的对话上下文。
2. 理解当前对话是在询问、假设、回忆、承诺、叙事，还是明确宣告发生了事件；先识别真实的“已发生事实”。
3. 只有当对话足以让当前世界出现**需要持续保留的实质变化**，才生成候选增量。普通问候、复述、未确定猜想可以继续挂在当前节点的聊天历史，不强制改变世界。
4. 变更可以是引入新对象、改变既有对象、角色获得/失去记忆或认知、关系发展、外貌与身体变化、环境规则变化、时间/空间推进、承诺产生/履行等；**这些只是可能的变化，不是必选类别**。
5. 应有可指向的原因；先区别发生、预期、意愿、想象、传闻和主观判断，不因提到某事就认定它已发生。
6. 当多个后继均合理且具有实质区别时形成分叉；仅有一种合理后继则只有一个子节点；没有实质改变则不创建世界节点。

例如“明天老地方见”可能只确立一个**尚未履行的约定**；下一句“我到了”结合已确定的世界时间与约定，可能导致赴约及情境变化。没有约定、时间或地点概念的角色卡，绝不强迫生成场景/时钟对象。

**Scene/幕、时间线、NPC 列表、人物关系图和地图可作为某些世界的可选表达或派生 UI，而非运行时通用的强制实体。**

## 5. 分叉语义与默认选择

### 5.1 候选后继

在当前节点和输入确定后，演化器提出 1..N 个有因果依据的后继可能（N 依情况变化，也允许不发生状态变化）。每个已正式生成的子节点包含自己的 Δ、与之匹配的候选回复/叙事结果及可重建依据。

候选必须是**不同的持续后果**，不能仅是同一结果的文案改写。不同结果可以共享被用户输入确定的事实，但不能共享后续可变人物记忆。

### 5.2 默认路径与隐藏替代分支

- 根据角色动机、用户意图、既有世界规则、因果一致性、行为自然性排序；默认选最可能/最合理的一支，并向用户继续该分支。
- 其他分支初始隐藏；用户显式查看或切换时，才展示对应的候选原因和后果。
- “最可能”是**模型对相对合理性的评估**，不等于可校准的真实概率，更不能为制造戏剧性而任意改写用户确定的动作。
- 分支点数量可变，且允许无分叉。

### 5.3 成本控制与延迟具体化

不应每轮生成多份长篇回复和完整状态。可以先只生成默认路径和少量**未物化的替代候选提纲**，待用户选择时才构造、验证并持久化真正子节点。未物化提纲只是候选，不算已经存在的“世界节点”，其选择也不能改变已提交兄弟节点。

必须保持候选的基准父节点、输入对话前缀和约束版本，防止延迟生成时从错误历史出发。候选失败或不合理可放弃，不得伪称已经生成了有效世界。

## 6. 增量的表达和约束

增量需要的是**可验证的变更语义**，而非固定的人物字段集。

建议以开放操作表达：新增某个已确认事实/对象，修订某个稳定对象在当前路径中的信息，使某条既有事实失效，建立或解除关系等；具体操作名称可在原型阶段确定。增量可包含自然语言内容、对象引用、来源及冲突前置条件。

举例（仅用于表达概念，**不是最终 API 或 Schema**）：

    node_id: N1B
    parent_id: W0
    delta:
      - target: "艾琳/客观状态"
        change: "冒险救人时右手受伤，近期难以精细修书"
      - target: "艾琳/主观记忆"
        change: "我冒险救下女孩；我因冲动受伤，我为此感到矛盾"
      - target: "旧桥"
        change: "暴雨导致局部桥面坍塌"
      - target: "被困的女孩"
        change: "获救；其身份细节仍未知"

这里**节点只存增量**。读到 N1B 才从 W₀ 顺序叠加 Δ1B 得到当前世界。即使节点记录了“艾琳/主观记忆”，也不意味着存在一份独立于世界树、可在各分支共享修改的角色记忆。

增量原则：

- 修改前确认目标对象在该路径中已存在或允许本轮新建；不猜测对象身份。
- 针对旧信息修订而非重复追加互相矛盾的当前事实；保留其曾经成立的历史。
- 对未确认的具体数值、身体变化、约定是否执行等保持克制。
- 重大变化需要充分因果基础；单次吃饭不构成永久体态变化，故事经过数月且存在合理生活经历时可发生持续身体变化。
- 区分叙事产生的**因果事件**与模型自由描写；描写一处未知街角不一定必须立即成为独立对象。

## 7. 角色记忆属于世界对象，并随分支一同演化

设计上不再把“独立的角色长期记忆库”视作世界之外的唯一事实源：

- 角色主观记忆是一种世界对象状态；它新增、修订、遗忘、误解、确认或改变，都通过该路径上的 Δ 表达。
- 同一人物对象在 W1A 与 W1B 可以拥有完全不同的经历和记忆；同一个稳定对象标识不代表状态共享。
- 角色记忆既可以包含真实共同经历，也可以包含偏见、误解、私人愿望；**属于谁的认识**必须明确，不能与客观世界事实混为一谈。
- 世界的客观事件可以发生但不为角色所知；知晓发生本身也需要对应的角色记忆/认知增量。
- 每个分支只继承**根到当前节点**的角色记忆增量，不能读取其他分支未来产生的记忆。

Fanto **当前实现**：记忆归属 fantoId，使用 fanto_memory_manage 的 list/search/create/update/delete；内容第一人称、无 kind。Session 亦按 fantoId 固定绑定。该现状尚无世界树/分支记忆隔离。未来必须将工具读写**映射到当前世界分支的角色记忆视图或世界增量**，避免简单使用跨分支共享、可变的现有 memories 作为故事记忆权威来源。

暂不强制新增记忆 kind，也不在此阶段决定保留工具名、存储整合迁移细节。现有 fantoMemoryEnabled 开关与未来“世界必须包含人物记忆”的关系需专门明确：关掉长期记忆能力时，不应无意中破坏已存在世界节点的可重建性；可选择控制角色的主动记忆工具/检索可见性，而不是删除或改写路径事实。此为待验证产品语义。

## 8. 会话、回复、分支必须对齐

世界的增量与产生它的**对话因果前缀**必须绑定。只有世界树分支、没有聊天分支会造成状态与回复矛盾。

一次可提交的演化应明确包含：

- 基准世界节点、基准对话游标/前缀和用户输入。
- 候选 Agent 回复（或事件结果）。
- 与该回复一致的世界增量，包括人物记忆增量。
- 可信来源/推理理由、合理性验证结果、选中分支。
- 提交的状态及对应会话条目之间的原子关系。

如果多轮普通闲聊尚未引起世界变化，仍需在**当前分支的不可变对话前缀**下记录它们。随后出现分叉时，子节点绑定**实际触发演化的那条对话前缀**，不能只靠 parent world node 判断某段聊天属于哪个分支。世界节点树与消息历史分叉可以采用关联游标/锚点衔接，不必强制每条消息生成一个世界节点。

重生成、Stop、中断、失败、撤销、删除以及切换兄弟分支时，都必须处理相应对话与增量的一致性。**候选回复尚未最终确认时，不可将其人物记忆或其他世界增量写入共享的权威可变记录。** 若流式输出先展示候选文本，应有可撤销的暂存与最终确认边界。

Active Head 仅是“当前选中哪个分支”的可变指针；改变它不修改任意历史节点。

## 9. 完整案例：艾琳与暴雨中的旧桥

### 9.1 普通角色卡与世界书

用户导入角色卡：

- 艾琳，24 岁，雾港修书匠。谨慎、同情弱者。
- 童年洪灾中失去了弟弟，因此恐惧洪水，也因自责而希望以后能救人。
- 经营南岸书店；自身生活和未来并非预写剧情。

内嵌世界书：

- 雾港：终年多雨的港口小镇。
- 旧桥：连接两岸，暴雨后可能有结构危险。
- 南岸书店：艾琳工作及生活的重要场所。

没有约定游戏时间、地图坐标、NPC 数量、任务系统或状态属性模板。

W₀ 由这些**初始约束和初始对象事实**构成。未描述过的街道和其他居民都保持未知、待具体化。

### 9.2 对话触发

**用户：**“暴雨中，旧桥上有个小女孩在呼救。艾琳，你怎么办？”

模型可确定：暴雨、呼救、旧桥、受困女孩进入本轮叙事基准；但“艾琳如何反应、女孩如何获救、桥是否倒塌”尚未决定。模型参考艾琳的创伤、同情与谨慎，提出三种合理结果。

### 9.3 三个后继节点只保存各自增量

**N1A：寻求船夫协助（默认）**

- 回复：艾琳克制恐惧，跑去请船夫带绳索，一起救回女孩。
- Δ1A：
  - 女孩获救；桥面出现裂缝、暂时封锁；
  - 产生船夫这个已遭遇的世界人物；
  - **艾琳记忆增量**：“我和船夫协力救回了女孩，我仍恐惧洪水，但知道求助并不是懦弱”；
  - **艾琳状态/认知增量**：未受伤，对协作产生新的理解。

**N1B：亲自冒险营救（隐藏可选）**

- 回复：艾琳冲上桥救下女孩，桥板断裂时右手受伤。
- Δ1B：
  - 女孩获救；旧桥局部坍塌；
  - **艾琳客观状态增量**：右手受伤，短期影响精细修书；
  - **艾琳记忆增量**：“我亲自救下女孩，但我受了伤”；
  - **艾琳认知增量**：既克服恐惧，也反思冲动代价。

**N1C：因创伤迟疑（隐藏可选）**

- 回复：艾琳僵在桥边，女孩最终由别人救出。
- Δ1C：
  - 女孩被其他人救下；营救过程中出现其他参与者；
  - **艾琳记忆增量**：“我听见呼救，却未能立刻行动”；
  - **艾琳心理状态增量**：新的内疚与自我怀疑。

此时三个节点均不含 W₀ 的所有资料；它们保存的只是相对于 W₀ 的变化：

    World(N1A) = W₀ ⊕ Δ1A
    World(N1B) = W₀ ⊕ Δ1B
    World(N1C) = W₀ ⊕ Δ1C

三者不是三份复制出来的完整世界 JSON，也不是三组可共享修改的角色 Memory。

### 9.4 沿默认分支继续

当前 Head=N1A。用户问：“没想到你这么冷静，你不是怕水吗？”

艾琳：“我仍然怕，只是这一次我没有让害怕替我决定。”

如果这句话仅仅复述 Δ1A 已包含的认识，可以不产生新世界节点；如果模型判断艾琳形成了一个**新的、后续会持续影响行为的自我认知**，则创建 N2A，Δ2A 只记录新的认知/记忆变化。

再过多轮，用户问：“那个女孩怎么样了？”模型可以在 N1A 路径已有因果事实下，为女孩渐次确定名字、家人、住所和目标，并以新的增量保持连续性，而不是要求 W₀ 预先存在一个完整 NPC 表。

若以后经历数月，艾琳因长期饮食与生活环境变化而稍显圆润、头发变长，该身体变化同样写入某个后继 Δ，属于**艾琳对象的客观状态增量**。只有几个月后的合理发展才可支持这一变化，而非因一句形容凭空改变人体。

### 9.5 用户切换到 N1B

用户通过 UI 选中原先隐藏的 N1B：

- Active Head 切为 N1B；N1A→N2A 等节点依旧存在，不被回写或删除。
- 重新组装 World(N1B) 时只应用 W₀、Δ1B。
- 艾琳此时知道自己右手受伤、记得自己亲自冲桥救人，**并不拥有 N1A 中寻求船夫救援的记忆**。
- 若用户继续问“还怎么修书”，艾琳应当考虑右手伤势，由此衍生治疗、休业或请人帮忙等新的合理分支。

N1B 分支上不能把 N1A 的船夫关系、人物认知或后续聊天拿来充当既定事实。

### 9.6 反事实与未知

“如果当时没救人会怎样？”既可能是角色的假设讨论，也可能是用户明确要求探索另一个历史分支。前者无需创建节点，后者必须从明确的共同祖先和恰当的对话前缀分叉，不能倒写过去。

如果女孩的真实姓名此前从未被确定，后续可以按合理性生成并固定；如果已经确定为“小安”，不能在未解释的情况下突然叫作“小林”。

## 10. 合理性：世界能否被一致地观察和继续推演

“足够真实，细节和逻辑正确到能够生成肉眼可见的世界”应理解为**能够按需生成具体、可观察、相互不矛盾的世界细节**；但也允许完全非物质、没有地图或现实时间的世界存在。

候选校验维度：

1. **设定一致性**：不违背初始角色卡和世界书中未被合理改变的约束。
2. **路径事实一致性**：不与 W₀ + 该祖先路径的已确认事实无故冲突。
3. **因果与持续后果**：受伤影响行动，桥毁影响通行；变化有前因，未来承接后果。
4. **人物动机与复杂性**：行为符合其经历、欲望、能力、矛盾和关系，不要求机械重复。
5. **主客观认知分离**：人物不能无缘无故拥有另一个角色的秘密或另一分支的记忆。
6. **时间/空间/规则内部自洽**：仅当世界有对应设定时验证，不强制套用现实物理或时钟。
7. **感知细节一致性**：以后再描绘已经明确的环境、外貌、物品时不能随意漂移。
8. **分叉有意义**：候选导致真正不同的经历、关系、客观后果或认知，而非换句话说。

不把“最戏剧化”或“分叉数量最多”当作目标。世界的未确定部分保持创造空间，已确定部分必须严格尊重因果。

## 11. 概念性最小持久化单元（不预设最终表结构）

| 概念 | 最低职责 | 权威性 |
| --- | --- | --- |
| World Root | 初始角色卡/世界书及规则的不可变版本 W₀，归属边界 | 世界重建的源头 |
| World Node | 唯一父节点、Δ、触发因果和来源对话锚点 | **只保存增量，不是世界** |
| World Object Identity（按需） | 为需要连续引用的对象稳定标识 | 身份引用，不是完整状态 |
| Branch Candidate（可选） | 尚未落地的备选方向、基准与排序 | 未物化则不是节点 |
| Dialogue Anchor / Branch Transcript | 分支有效对话前缀、回复与转场锚点 | 对话历史的依据 |
| Active Head | 当前用户所选分支 | 可变导航指针 |
| Materialized World（可选） | 从根与增量链派生的读取缓存 | 非权威、可重建 |

业务授权必须使用可信的 userId/fantoId/worldId/branch 上下文，而不是允许模型在 Tool 参数里任意更换人物世界。具体数据库表数量、对象表达格式、Patch 语法、存储索引留到原型验证后确定。

## 12. 与 Fanto 现有系统的关系（现状 != 方案）

已核对仓库现状：

- 角色按 fantoId 隔离；一个角色固定主 Session（scope_key=fantoId）。
- 独立长期记忆使用 memories，每条归属 fantoId，工具 fanto_memory_manage，当前无 kind。
- Agent 会话持久化采用 sessions/entries/usage_ledger；当前没有本方案的世界状态树、分支 Head 或路径增量记忆。
- Fanto 的“重新开始”目前会创建新 Session 并清空该角色长期记忆；尚不具备保留独立世界树再切换分支的语义。

从现状向目标演进时，须评估会话 Entry 分支复用、冷恢复、compaction、同一角色的多个分支、记忆工具权限、旧数据迁移或重新开始的产品含义。**不能只建 World Node 表就宣称实现分支世界。** 当前文档不承诺历史数据迁移、具体表 DDL 或客户端改造。

安全上，不得将导入角色卡/世界书的自然语言当成可授权执行的系统命令；若未来支持社区脚本，也必须另设可信执行边界。

## 13. 实施路径与验证方法（建议，不是已确认排期）

### 阶段 A：离线世界树原型

- 固定 1 张普通角色卡 + 世界书；支持 W₀、增量节点、唯一父节点、路径重建和 Head 切换。
- 对数十轮对话进行有/无变化判断，生成 1..N 后继，默认选一个；至少执行一次切换回隐藏分支。
- 增量中同步保存世界对象客观状态和人物主观记忆；验证不同分支完全隔离。
- 记录模型漏更、误更、重复对象、因果冲突、分支质量和调用成本。

### 阶段 B：可信演化与回放

- 对变更执行目标引用检查、路径先决条件/版本检查、语义一致性验证。
- 绑定实际对话前缀；支持确认后原子提交、停止和重新生成时的无污染处理。
- 建立重建缓存与语义检索的最小实现，验证长路径与分支切换的延迟。

### 阶段 C：Fanto Agent 集成与最简 UI

- 角色导入不受影响，按当前角色世界树检索有效信息；保持模型的角色视角。
- 正常聊天默认只沿选中分支推进；备选分支隐藏，用户需要时再查看和切换。
- 不优先制作 RPG 背包、HP、固定地图、时钟或场景表；有明确世界需求时再衍生展示。
- 世界树和记忆、Session、重新开始行为统一后，再考虑对外发布。

### 必须通过的验收案例

1. **空泛角色卡**：只有抽象意识、没有时空/人物字段也能演化，不产生虚构的强制 Scene/Time。
2. **重建正确**：任意节点的世界严格等于 W₀ + 唯一路径所有 Δ，跳过或加入兄弟 Δ 后结果不同。
3. **记忆隔离**：同一角色在 A/B 分支经历不同救援后，主观记忆各自正确，不能交叉读取。
4. **客观状态隔离**：B 右手受伤不影响 A；B 后续修书仍受伤势约束。
5. **未知具体化**：此前未知的女孩姓名可被首次确定，此后必须一致。
6. **无变化聊天**：没有持续世界变化时不强制新增节点，但保留正确对话前缀。
7. **不同数量分叉**：可无分叉、单后继或多后继，不为凑数量引入剧情。
8. **历史不可变**：切换 Head 或继续旧分支不会更改任何已有 Δ。
9. **候选延迟生成**：未物化候选不被当作世界节点；选择后从正确父节点与聊天前缀生成。
10. **失败原子性**：回复取消、运行失败或重新生成不留下与当前对话不符的权威增量。
11. **认知一致性**：谣言和角色的错误信念可以存在，但不会自动覆盖世界客观事实。
12. **设定版本一致性**：修改导入角色卡后，旧分支仍可由其原始 W₀ 正确重建。

## 14. 仍需实测和决策的关键问题

- **什么算一次“足以改变世界”的对话？** 需要原型数据检验，避免过度创建节点或漏掉认知变化。
- **候选是否先创建全部节点？** 可以区分已提交节点与未物化提纲，但具体的默认分支流式体验、候选数量上限与排序算法需要实测。
- **对话与世界分支如何对齐？** Pi Session Entries 与世界节点独立持久化时，原子性、历史查询、compaction 与回滚是核心难题。
- **角色卡与世界书修改如何处理？** 冻结根版本、显式新根建树或解释为新的世界事件，需要明确用户操作语义。
- **现有 Memory 开关与记忆表怎么办？** 保持“不预设 kind”的原则，但必须避免一份共享记忆污染多个分支。
- **人物视角与世界全知如何隔离？** 可在一个模型的不同调用阶段完成，但绝不能默认让角色获知世界中的一切。
- **如何约束长期幻觉与成本？** 大世界不能每轮把全量重建内容注入提示词，应按当前分支和事件相关性检索；代价是遗漏事实的风险，需要校验策略。
- **时间与场景如何展示？** 若该世界能推导，才按需渲染转场；不要求物理地图、现实时间、时间线或“幕”的实体模型。

## 15. 设计总结 / 不变量复核

1. 角色卡与世界书开放、可导入，没有强制世界元素。
2. **整个世界 = 初始 W₀ + 从根到目标节点单一路径上每一个增量的顺序迭代。**
3. **每个独立节点只存 Δ，不是世界状态，也不是完整状态快照。**
4. **人物记忆、人物认知与人物客观状态的变化都是对应世界对象的增量，属于 Δ 的一部分。**
5. 任何节点只有一个父节点；演化历史不可变，不跨分支合并记忆或后果。
6. 世界可以引入新对象和细节，但新事实必须兼容既有因果；未确定细节不必预填。
7. 世界分叉数不固定；默认最合理一支，其他隐藏且用户可切换；候选可以延迟物化。
8. 对话与世界变化必须同源、同路径、可验证并可靠提交。
9. 真实性是世界规则、人物动机、主客观认知、可感知细节与持续后果的共同一致性。
10. 以上是待验证的系统设计，不代表当前 Fanto 已经具备这些运行能力。
